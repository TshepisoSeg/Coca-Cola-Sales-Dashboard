# Coca-Cola-Sales-Dashboard
AI-powered Power BI sales dashboard

📊 Power BI Sales & Financial Analytics Dashboard
📌 Project Overview

This project is an interactive Power BI dashboard designed to analyze sales performance, financial metrics, and regional trends. It leverages Power Query for data cleaning and transformation and includes advanced Power BI visuals for insightful business analysis and decision-making.

🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- Excel (Dataset Source)
- Data Visualization
- Business Intelligence

📂 Project Workflow
1. Imported dataset from Excel using Power Query for data cleaning and transformation
2. Designed dashboard layout with structured headers and visual containers
3. Built interactive and analytical visuals to explore business performance

📊 Key Features & Visuals
🤖 AI-Powered Q&A Visual
Allows users to ask natural language questions and receive instant insights from the dataset.

📈 Key Influencers Visual
Identifies key factors affecting profit margins across different brands.

🌍 Map Visualization
Displays sales distribution across different geographic regions.

📑 Financial Matrix
Analyzes key financial metrics such as:

1. Price per unit
2. Operating profit
3. Sales performance
   
⏱️ Dynamic Timeline
Enables users to filter and analyze data across different time periods interactively.
